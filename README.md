<h2>9. Психологические ловушки: когнитивные искажения в анализе</h2>

<p>Даже профессиональные аналитики подвержены систематическим ошибкам мышления. Осознание этих искажений &mdash; первый шаг к их нейтрализации.</p>

<h3>ТОП-5 искажений в спортивном прогнозировании</h3>

<ul>
	<li><strong>Ошибка выжившего:</strong> Анализ только успешных стратегий без учета тех, что привели к разорению.</li>
	<li><strong>Confirmation bias:</strong> Поиск информации, подтверждающей уже принятое решение.</li>
	<li><strong>Ошибка игрока:</strong> Убеждение, что прошлые результаты влияют на независимые будущие события.</li>
	<li><strong>Эффект привязки:</strong> Чрезмерное влияние первой полученной информации на последующие решения.</li>
	<li><strong>Hindsight bias:</strong> Иллюзия, что исход события был предсказуем постфактум.</li>
</ul>

<p>Борьба с этими искажениями требует ведения детального журнала всех решений и их результатов для объективной ретроспективы.</p>
